# 🏨 Palace City Hotel

### A Modern Hotel Website and Management System

Welcome to **Palace City Hotel**, a hotel website project developed to provide visitors with an easy way to explore hotel rooms, learn about available services and make enquiries.

The project combines an attractive and user-friendly frontend with a backend system that handles information and communication with the database.

---

## 🌟 About the Project

Palace City Hotel is a web-based hotel project designed to give visitors a simple and convenient online hotel experience.

Visitors can browse through the website, view available rooms, explore hotel services and submit enquiries. Behind the scenes, the backend manages the information and processes requests from the website.

The project was developed as part of my practical learning and experience in web development.

## ✨ Key Features

- **Hotel Homepage:** A welcoming homepage that introduces the hotel.
- **Room Listings:** Visitors can explore different room categories and their details.
- **Room Details:** Individual pages provide more information about selected rooms.
- **Hotel Services:** Visitors can learn about the services offered by the hotel.
- **Booking Management:** A system for handling booking information.
- **Contact and Enquiries:** Visitors can send messages and enquiries.
- **Admin Authentication:** Provides a login system for authorised administrators.
- **Database Management:** Stores and manages important hotel information.

## ⚙️ Running the Project

To run the project on your computer:

1. Download or clone this repository.
2. Open the project folder in your code editor.
3. Open the backend folder in your terminal.
4. Install the required dependencies using `npm install`.
5. Configure your environment variables, including your MongoDB connection.
6. Start the application using `npm start`.
7. Open your browser and visit `http://localhost:3000`.

**Note:** A properly configured MongoDB database and environment variables are required for the backend to work.
